# 施工抽查表單產生器（整合版）

監造／工程單位用的施工抽查標準表管理工具。單一 HTML 檔案、免安裝、免伺服器，瀏覽器打開即可使用；資料版本管理、Excel 匯入比對、紀錄表、流程圖（程序表）、呈核版 Word 匯出、Google Sheet 雲端同步，全部整合在這一個檔案裡。

## 🚀 線上使用

本專案已部署在 GitHub Pages，直接打開以下網址即可使用（不需下載、不需安裝）：

```
https://你的帳號.github.io/你的repo名稱/
```

> 💡 若要在本機測試，直接用瀏覽器開啟 `index.html` 即可，但**雲端同步功能**（見下方）在 `file://` 本機開啟模式下無法使用，必須透過網址（`http://` 或 `https://`）開啟，這也是部署到 GitHub Pages 的主要原因。

|---|---|

| 🧭 流程圖（程序表） | 依施工階段自動產生流程圖，標示★施工檢驗停留點／※安全衛生查驗點，可匯出 PNG／SVG |

| 📄 匯出標準版（呈核版） | 把標準資料表整理成正式 Word 文件格式，供呈核歸檔 |
| ☁️ 雲端同步 | 列印／匯出 Word 時自動把紀錄表資料與照片同步寫入您自己的 Google 試算表（見下方設定） |

## ☁️ 雲端同步設定（選用功能）

把每次填寫的紀錄表資料與照片，自動同步一份到您自己的 Google 試算表存查。此功能完全免費，不需要任何付費雲端服務。

### 第一步：部署 Google Apps Script

1. 開一份新的 Google 試算表
2. 選單「擴充功能」→「Apps Script」
3. 把本專案 [`雲端同步_AppsScript範本.gs`](./雲端同步_AppsScript範本.gs) 的內容整份貼上（取代預設內容）
4. 右上角「部署」→「新增部署作業」：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 第一次部署會跳出 Google 未驗證警告，點「進階」→「前往（專案名稱）(不安全)」完成授權
6. 複製部署完成後取得的網址（結尾是 `/exec`）

### 第二步：在系統裡設定

1. 開啟系統，點頁首「☁️ 雲端同步設定」
2. 貼上剛才複製的網址，勾選「啟用自動同步」
3. 點「🔌 測試連線」確認顯示「✓ 連線成功」
4. 儲存即可

之後在「紀錄表」分頁按下「列印」或「匯出 Word」時，會自動同步該筆資料到您的 Google 試算表：
- **「紀錄表資料」分頁**：一列＝一個管理項目
- **「照片」分頁**：一列＝一張照片，自動存入您 Google 雲端硬碟的「施工抽查照片」資料夾，並用 `=IMAGE()` 公式顯示縮圖

> 同步網址只存在您瀏覽器本機（localStorage），不會寫進這份 HTML 檔案、也不會傳給任何第三方。即使這個 repo 是公開的，也不會外洩您的試算表網址或填報資料。

### 表單編號自動接續（需先完成上方雲端同步設定）

啟用雲端同步後，切換「紀錄表」分頁的分項工程（工項）時，系統會自動向您的 Google 試算表查詢該工項（例如 `E08`）目前已使用過的最大流水號，並自動帶入下一號（例如 `E08-0037`）。每個工項各自獨立編號，互不影響，不需要再自行確認是否重複或跳號。

- 若尚未啟用雲端同步，或查詢逾時/失敗，會自動退回離線預設編號（`{工項代碼}-0001`），並提示您自行確認填寫正確的流水號。
- 這個功能需要重新部署過的 `雲端同步_AppsScript範本.gs`（內含 `nextFormNo` 查詢功能）；若您是舊版部署，請重新貼上最新版 `.gs` 內容並「管理部署作業」→ 新版本重新部署。

### 手機填報模式

手機（螢幕寬度小於 768px）開啟時會自動進入此模式，電腦上可用「紀錄表」分頁的「📱 手機填報模式」按鈕切換。

- 大按鈕逐項點選 ○合格／╳不合格／／不適用，輸入實測值與備註，抽查標準可展開查看
- 上方即時顯示填寫進度與不合格項數
- 📷 直接拍照或從相簿選取照片，可加說明、可移除
- 可切換大類／分項工程、修改抽查位置、人員、日期等基本資料
- 底部固定按鈕：☁️ 提交雲端、📄 匯出 Word、🖨 列印（匯出／列印本身也會自動同步雲端，同一筆若先按「提交雲端」再匯出，雲端會有兩份，請擇一）
- 所有輸入都寫回同一份表單資料，切回標準版面即可看到；列印／PDF 一律使用標準版面

### 疑難排解

| 現象 | 原因 / 處理方式 |
|---|---|
| 測試連線出現「Failed to fetch」 | 最常見原因是用 `file://` 本機開啟檔案，瀏覽器會擋掉跨網域請求，**必須透過 GitHub Pages 這類 http(s) 網址開啟**才能正常同步 |
| 出現 Google 登入／權限警告頁 | Apps Script 部署時「誰可以存取」沒有選「所有人」，需要編輯部署作業重新設定 |
| 修改過 `.gs` 程式碼但沒生效 | 需要「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」重新部署，單純存檔不會更新線上網址 |
| 想暫停同步但不想刪除網址 | 「☁️ 雲端同步設定」取消勾選「啟用自動同步」即可，網址會保留 |

## 🔧 如何部署到 GitHub Pages

1. GitHub 新增一個 **Public** repository（免費方案的 GitHub Pages 僅支援公開儲存庫；本專案不含任何使用者填報的敏感資料，公開無虞）
2. 把 `index.html` 上傳到該 repository 根目錄（**檔名務必是純英文 `index.html`**，中文檔名容易在網址列出現編碼問題導致 404）
3. 「Settings」→「Pages」→ Source 選「Deploy from a branch」，Branch 選 `main`，資料夾選 `/ (root)`，儲存
4. 等 1-2 分鐘後，網址會出現在同一頁面，格式為 `https://你的帳號.github.io/repo名稱/`

## ⚠️ 已知限制

- 所有資料僅存在瀏覽器分頁的記憶體中，**重新整理頁面會清空**（回到內建預設標準資料庫）；若已設定雲端同步，紀錄表資料在列印/匯出當下就已經寫入 Google 試算表，不受此限制影響，但版本管理中新建立的 Excel 匯入版本不會持久化保存
- 大量照片同步時，上傳到 Google 雲端硬碟需要時間，列印/匯出前會顯示等待畫面
